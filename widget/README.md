# 桌面字幕小窗（M4）

Tkinter 无边框置顶小窗，订阅 `ws://127.0.0.1:8766` 的 `subtitle` 事件并渲染。

## 启动

```
venv\Scripts\pythonw.exe -m widget.widget    无控制台窗口（启动.bat 用的就是这个）
venv\Scripts\python -m widget.widget          带日志输出，排查时用
```

需要 tkinter（Python 官方安装包自带；`安装依赖.bat` 用 `py -3` 建 venv 即有）。
若 venv 的 Python 没带 tkinter，`启动.bat` 会回退到系统 Python + `venv\Lib\site-packages` 启动小窗。

## 交互

| 操作 | 效果 |
| --- | --- |
| 左键拖拽 | 移动窗口，松手后位置写入 `state.json` |
| 右键 | 弹出菜单 |
| 菜单·显示/隐藏原文 | 中文源默认不显示原文 |
| 菜单·窗口置顶 | 默认置顶，可取消 |
| 菜单·字号 16/20/26 | 默认 20 |
| 菜单·清空字幕 | 清掉历史与上句 |
| 菜单·退出 | 保存状态并退出 |

## 布局

- 灰色小字：前 2 句历史（`HISTORY = 2`）
- 白色粗体：当前中文字幕
- 灰色次行：原文（非中文源才显示）
- 底部：连接状态 + 端到端延迟（绿=已连接，橙=重连中）

## 实现要点

- 断线自动重连，退避 1s→10s；状态通过 `queue.Queue` 交给主线程，100ms `after` 泵刷新
- 拖拽偏移用 `x_root - winfo_x()` 计算，点在任意子控件上都不会跳位
- 所有控件都绑定拖拽事件（因为窗口无边框）
- 命令行/状态颜色常量在文件顶部（`BG`/`FG`/`DIM`/`OK`/`WARN`）
